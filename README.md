# 🧠 Data Analytics Portfolio

Welcome to the Data Analytics Portfolio repository. This repository highlights end-to-end analytical projects focused on solving real-world business challenges through data. Each project folder contains a complete, self-contained analysis, including data preparation, processing, visualization, and final presentation materials.

## 📁 Project Structure

All individual projects live in their own folders within this repository. Each project typically contains:
- **Case Study folder** (with R scripts and data files)
- **Presentation folder** (with slides used for sharing findings)

## 📂 Projects

### 1. [Capstone Project – Cyclistic Bike-Share Analysis](./capstone-cyclistic)
**Goal:**  
Analyze and identify the behavioral differences between *casual riders* and *annual members* using historical trip data from Cyclistic, a fictional bike-share company in Chicago.

**Outcome:**  
Provided detailed insights and visualizations to support marketing strategies that aim to convert casual riders into members.

**Contents:**
- `./capstone-cyclistic/case-study-r/CaseStudy_A` – All R scripts and data preparation workflows
- `./capstone-cyclistic/presentation/` – Google Slides presentation summarizing the findings

## ✅ Tools and Skills Demonstrated
- R & RStudio for analysis
- Data cleaning, transformation, and visualization
- ggplot2, dplyr, and tidyr for EDA and plotting
- Adhering to the six-step data analysis process (Ask, Prepare, Process, Analyze, Share, Act)
